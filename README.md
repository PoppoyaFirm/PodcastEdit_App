# Podcast Editor

一人語りのポッドキャストを、半自動で編集する Windows 用のアプリケーション。
録音を文字起こしし、フィラー(「えー」「あのー」など)・言い直し・長すぎる間をカットの候補として示す。利用者は候補を聴いてカットするか残すかを選び、構成の並べ替え・ジングル・BGM・エフェクトを加えて書き出す。処理はすべて PC の中で行い、音声を外部に送らない(AI連携を使う場合を除く。AI連携は既定でオフ)。

このリポジトリは配布専用であり、インストーラーと説明だけを置く。

## ダウンロード

[Releases](https://github.com/PoppoyaFirm/PodcastEdit_App/releases) から、最新バージョンの次のファイルを入手する。

| ファイル | 内容 |
|---|---|
| `PodcastEditor-Setup-<バージョン>.exe` | インストーラー |
| `PodcastEditor-Setup-<バージョン>.exe.sha256.txt` | インストーラーの SHA-256 |
| `PodcastEditor-<バージョン>-lgpl-sources.zip` | 同梱している LGPL の部品(PyAV)のソース |
| `latest.json` | アプリ内の更新が読む情報(利用者が開く必要はない) |

ダウンロードしたインストーラーが壊れていないかは、PowerShell で次のように確かめられる。表示された値が `.sha256.txt` の値と一致すればよい。

```
Get-FileHash .\PodcastEditor-Setup-<バージョン>.exe -Algorithm SHA256
```

## 動作環境

### 必須

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11(64 ビット) |
| CPU | 64 ビットの Intel / AMD の CPU、4 コア以上 |
| メモリ | 8 GB |
| GPU | 不要(CPU で文字起こしする) |
| ディスクの空き | 6 GB(アプリ・ffmpeg・文字起こしモデルで約 3.7 GB。プロジェクト 1 本につき約 0.35 GB、WAV の書き出し 1 回につき約 0.5 GB) |
| ネットワーク | 初回のみ約 3.2 GB のダウンロード(文字起こしモデル・ffmpeg) |

GPU を使わない場合、72 分の収録の文字起こしに、10 コアの CPU(Intel Core i9-10900K)で約 48 分を要した。CPU の性能によってはさらに長くかかる。

### 推奨

| 項目 | 内容 |
|---|---|
| OS | Windows 11(64 ビット) |
| CPU | 6 コア以上 |
| メモリ | 16 GB 以上 |
| GPU | NVIDIA GeForce RTX 20 シリーズ以降、VRAM 6 GB 以上、ドライバー 572.61 以降 |
| ディスク | SSD、空き 20 GB 以上 |

NVIDIA の GPU を使う場合、72 分の収録の文字起こしは約 4.5 分で終わる(GeForce RTX 3070 での実測)。GPU を使うには、アプリの設定から「GPU 高速化パック」(約 0.55 GB)を追加で取得する。

### 対応していないもの

- AMD・Intel の GPU による文字起こし(CPU で文字起こしする)
- macOS・Linux 向けのインストーラー

## インストール

1. インストーラーを実行する。管理者の権限は要らない。
2. このアプリには電子署名をしていないため、次の警告が出ることがある。
   - ブラウザ(Edge)で「一般的にダウンロードされていません」と表示された場合は、「…」→「保存」→「削除」の横の ▼ →「保持する」を選ぶ。
   - 「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選ぶ。
   - Windows 11 の「スマート アプリ コントロール」がオンの PC では、実行できない。
3. 利用規約に同意して進める。初回の起動時に、プロジェクトの置き場所と、文字起こしモデル(約 3.1 GB)のダウンロードを案内に従って決める。

## 更新

バージョン 2.3.2 以降は、アプリの中から更新できる。

- 設定の「更新」で「起動したときに、新しいバージョンが出ていないか確かめる」がオンの場合、起動時に 1 日 1 回まで確かめ、新しいバージョンがあればホームに知らせる。「今すぐ確かめる」でいつでも確かめられる。
- ホームのお知らせの「更新する」を押すと、インストーラーのダウンロード、内容の確認、アプリの終了、入れ替え、再起動までを自動で行う。プロジェクト・設定・文字起こしモデルはそのまま残る。
- 更新の情報には電子署名を付けており、署名とインストーラーの大きさ・SHA-256 が一致した場合にだけ入れ替える。
- 手で更新する場合は、新しいインストーラーを実行するだけでよい。

バージョン 2.3.1 以前を使っている場合は、一度だけ手でバージョン 2.3.2 以降のインストーラーを実行する。

## 不具合の報告

不具合を見つけた場合は、アプリの 設定 →「困ったとき」→「不具合の報告用の情報を作る」で情報を作り、内容を確かめたうえで、配布元に知らせる。

- この情報には、アプリ・PC・GPU の構成、各部品のバージョン、直近のエラー、ログの末尾が入る。音声・文字起こしの本文・アクセスキーは入らない。プロジェクト名と利用者名は伏せ字になる。
- GPU で文字起こしができない・遅い・途中で止まる場合は、「GPU で文字起こしを試す」にチェックを入れてから作る。
- アプリが起動しない場合は、インストール先の `pe.cmd report`(`%LOCALAPPDATA%\Programs\PodcastEditor\pe.cmd report`)で同じ情報を出力できる。
